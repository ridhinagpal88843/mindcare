# MindCare – Student Wellness Website

MindCare is a responsive, frontend-only student wellness website designed to encourage emotional well-being, mindfulness, and healthy self-care habits among students.

## Features
- Daily mood check-ins and mood history.
- Interactive guided breathing exercise.
- Self-care tips and wellness suggestions.
- Daily wellness reminders.
- Private journaling space.
- Save mood entries and journal data using browser LocalStorage.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- LocalStorage

## How to Run
1. Download or clone the project repository.
2. Open the `mindcare` folder.
3. Open `index.html` in a web browser.
4. Alternatively, use the VS Code Live Server extension.

## Deployment
MindCare can be deployed independently using Vercel.

- Framework Preset: Other
- Build Command: Leave blank
- Output Directory: `.`

## Project Type
Frontend-only web application. No backend or database is required. Mood entries and journal data are stored locally in the user's browser and are not shared with other users or devices.

**Note:** MindCare is an educational wellness tool and is not a substitute for professional mental health care.
